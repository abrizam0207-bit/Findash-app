💡 Panduan Backup ke Excel

Cara membuka file CSV di Excel

Langkah-langkah:
1. Klik "Export Excel" di atas → file .csv akan terdownload
2. Buka Microsoft Excel → File → Open → pilih file CSV
3. Jika muncul dialog, pilih "Delimited" → Next
4. Centang "Comma" sebagai delimiter → Finish
5. Data akan muncul rapi di kolom-kolom Excel

💡 Tips:
• Gunakan Google Sheets untuk buka CSV online
• File CSV bisa dibuka di Numbers (Mac) atau WPS Office
• Untuk backup lengkap, gunakan Backup JSON — bisa direstore kembali
